# Technical Specification

## סיווג אמינות אלמנטים
- **VERIFIED**: נתון שמקורו במידה מפורשת.
- **DERIVED**: נתון שחושב מנתונים מאומתים (עם תיעוד).
- **UNRESOLVED**: נתון חסר או סותר.
- **VISUAL ONLY**: אלמנט עיצובי בלבד.

## פורמטים
- IFC — מודל BIM
- DXF — גיאומטריה להמשך עבודה
- GLB/glTF — תצוגה בזמן אמת (ייצוא במטרים)
- JSON — מטא-דאטה

## בדיקות QA
- Overlay אורתוגרפי
- השוואת מידות
- בדיקת התנגשויות
- בדיקת רציפות בין קומות
- בדיקות ביצועים (FPS)
- בדיקת תאימות מובייל

## חוויית משתמש
- תמיכה מלאה ב-RTL (עברית) ו-LTR (אנגלית)
- מיני-מפה
- מעבר בלחיצת כפתור בין חללים
- התאמה אוטומטית לפורטרט/לנדסקייפ
- תמיכה בגירוסקופ (מובייל)
- הפחתת אנימציות לנגישות
